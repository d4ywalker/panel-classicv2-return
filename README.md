## Key Modules & Features

### 1. Power Up Store - In-Game Item Mall (pus.html / pus.js / pus.css)
- Web-based PUS shop integrated with Knight Online account balance.
- Item categories: Premium cards, scrolls, weapon enhancers, costumes, and utility items.
- Real-time cart calculation and one-click purchase delivery.

### 2. Top-Up & Billing Gateway (topup.html / topup.css)
- Secure payment gateway integration for automated server coin recharge.
- Multi-channel support (Credit card, PayPal, crypto, and local bank transfers).
- Transaction history and automated invoice verification (verify.php).

### 3. Leaderboard & Ranking System (ranking.html / ranking.js / ranking.css)
- Live server rankings: Top national points (NP), ladder rankings, and active clan ladders.
- Filter by Karus, Elmorad, or global server leaderboard.
- Detailed character profile inspector.

### 4. Multi-Language Localization Engine (translations.js)
- Instant client-side language switching without page reload.
- Full support for English, Turkish, Indonesian, and Spanish.

### 5. Launch Gateway & Coming Soon Portal (index.html / home.html)
- Countdown timer for server launch / grand opening events.
- Server rates showcase (EXP, Drop, Upgrade, Level Cap).
- Feature cards highlighting Clan War, Fair Play, and Anti-Cheat systems.

### 6. Content Management & Event System (news.html / event.html / guide.html)
- Patch notes and update announcement manager.
- Dynamic countdown timers for Lunar War, BDW, Chaos, and JR.
- Complete game guide, drop list, and crafting recipes wiki.

### 7. Secure Admin Control Panel (admin.php / loginadmin.php)
- Live GUI for managing server parameters, maintenance mode, downloads, and announcements.
- Direct database bridge (api.php, db.php, config.php) for MS SQL / MySQL databases.
- Role-based authentication and audit log.

## Technical Architecture

```
panel-classicv2-return/
|-- index.html                  # Coming Soon & Gateway Portal
|-- home.html                   # Main Dashboard & Server Realm
|-- pus.html / pus.js / .css    # Power Up Store (PUS) Web Shop
|-- topup.html / topup.css      # Payment & Billing Gateway
|-- ranking.html / .js / .css   # Player & Clan Rankings
|-- news.html / news.js / .css  # Server News & Updates
|-- download.html / .js / .css  # Multi-Mirror Client Downloader
|-- event.html / event.js / .css# In-Game Event Scheduler
|-- guide.html / guide.css      # Game Wiki & Guide System
|-- contact.html / terms.html   # Legal & Support Pages
|-- translations.js             # Multi-Language Localization Engine
|-- admin.php / loginadmin.php  # Secure Administration Panel
|-- verify.php / config.php     # Payment Verification & Server Config
|-- api.php / db.php            # Game Database Connector & REST Endpoints
\-- assets/                     # UI Graphics, Media, Audio & Item Icons
```
